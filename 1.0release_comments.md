This version changes how JuliaExcel works from using file-based communication between Excel and Julia (versions 0.2.17 and earlier) to using sockets with HTTP.jl on the Julia side and MSXML2.XMLHTTP.6.0 on the Excel side.

Together with the changes in version 0.2.17, this has led to improved latency and speed of one-way and two-way communication between Excel and Julia, as shown below.

| Test | v0.2.16 | v0.2.17 | v1.0 |
|---|---|---|---|
| Latency:</br>`JuliaEval("1+1")` | 7.16 ms | 6.41 ms | 1.10 ms |
| Two-way:</br>`JuliaCall("identity", vector of length 100,000)` | 1.555 s | 0.370 s | 0.274 s |
| One-way (Excel to Julia):</br>`JuliaCall("sum", vector of length 100,000)` | 1.452 s | 0.109 s | 0.113 s |
| One-way (Julia to Excel):</br>`JuliaEval("collect((1:100000).*pi)")` | 0.307 s | 0.264 s | 0.167 s |
